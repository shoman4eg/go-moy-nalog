# Contributing

Спасибо за интерес к проекту! Любые улучшения и предложения приветствуются.

## Как помочь

- Сообщить о баге через Issue.
- Предложить улучшение или новую фичу.
- Отправить Pull Request с исправлением или новым функционалом.
- Улучшить документацию и примеры.

## Перед отправкой Issue

- Убедитесь, что похожая Issue уже не создана.
- Описывайте проблему максимально конкретно.
- Приложите шаги для воспроизведения, ожидаемый результат и фактический результат.
- Укажите версию Go (`go version`), версию пакета и окружение.
- Не публикуйте токены, ИНН и пароли.

## Локальная разработка

Требуется Go 1.25 или новее.

```bash
# Установить golangci-lint в ./bin (один раз)
make init

# Отформатировать код (gofumpt + goimports + gci)
make format

# Запустить линтеры (golangci-lint + go-consistent)
make lint

# Прогнать тесты с детектором гонок и покрытием
make test

# Проверить всё сразу, ничего не изменяя (то же, что гоняет CI)
make check

# Открыть HTML-отчёт покрытия
make cover
```

Остальные вспомогательные инструменты (`gofumpt`, `goimports`, `gci`,
`go-consistent`) подключены через директиву `tool` в `go.mod` и запускаются
через `go tool`, отдельная установка не нужна.

## Соглашения по коду

- Клиент построен по образцу [google/go-github](https://github.com/google/go-github):
  один общий `service`-тип, `NewRequest` / `Do` / `BareDo`, обёртка `Response`,
  сигнатура методов `(*T, *Response, error)`.
- Весь публичный API живёт в одном пакете `moynalog`.
- Вместо стандартного пакета `errors` используется
  [`github.com/pkg/errors`](https://github.com/pkg/errors) — это проверяется
  линтером `depguard`.
- Новые эндпоинты покрываются тестами на `httptest`: проверяйте метод, путь,
  query, тело запроса и разбор ответа.

## Перед отправкой Pull Request

1. Создайте ветку от `master`.
2. Опишите в PR:
   - Что изменено.
   - Зачем это нужно.
   - Есть ли breaking changes.
3. Добавьте/обновите тесты.
4. Убедитесь, что `make check` проходит.

Отправляя Pull Request, вы соглашаетесь, что ваш код распространяется на
условиях лицензии репозитория (MIT).
